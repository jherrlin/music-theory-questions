# Music theory flashcard

A pure JavaScript and HTML app that shows flashcards with music theory questions.
It should have a space repetition algorithm that tracks answers and answers that are often answered wrong should be presented more often.
Data about question results should be saved in localstorage in the browser.

The questions on the flashcards should be like:
- What tones are in a specific chord
- What intervals are in scale X
- What tones are in scale X in the key of Y
- Give the user a overview page with all questions and answers. That page should be downloadable in a markdown format
- As a guiding tool, a user can show a mandolin fretboard that can show notes and intervals
